## 验收矩阵

| 领域 | 阻断验收 |
|---|---|
| V12 迁移 | V11 升级和空库均成功；既有账户、健康数据、计划、任务和报告不丢失 |
| 用户隔离 | 账户、设备、授权、导出、删除、申诉和注销资源不能跨用户访问 |
| 验证码 | 用途隔离、5 分钟、一次使用、失败限制；错误提示不泄露账户状态 |
| 设备安全 | 当前设备不可移除；移除单设备只撤销目标；退出其他设备保留当前设备 |
| 档案编辑 | 六分区可独立保存；关键字段标记重算；普通字段不标记；旧计划保留到新计划确认 |
| 饮食与风险 | 过敏和禁忌立即过滤建议；风险变化立即执行安全拦截 |
| 隐私版本 | 两类文件独立；旧版继续使用；新增授权只限制依赖它的新功能 |
| 授权撤回 | 计划、记录和报告立即停用；账户与数据权利保留；重新同意按现存数据恢复 |
| 手机换绑 | 双验证码；正常换绑保留当前设备；申诉换绑退出全部设备 |
| 数据导出 | 短信验证、24 小时限频、加密中文 PDF、脱敏、24 小时过期、密码不落库或日志 |
| 数据删除 | 支持类型和时间；预览准确；相关报告与计划版本删除；无关版本保留；失败整体回滚 |
| 账户注销 | 申请后全部退出；冷静期仅受限页；7 天内可恢复；期满不可恢复且手机号可重新注册 |
| 中文与视觉 | 页面、按钮、状态和错误中文；Android 手机/iPhone 可保留；主要控件 6 px 圆角 |
| 无障碍 | 窄屏、字体放大、键盘、读屏标签、减少动画与危险操作非纯颜色表达 |
| 范围 | AI 食物图片识别没有实现或提前接入 |
