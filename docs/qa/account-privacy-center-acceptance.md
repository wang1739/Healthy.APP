### A. 首次同意、撤回与入口边界

- [ ] 新用户未同意健康数据授权前，档案、饮食、饮水、运动、睡眠、任务的健康数据读写均被服务端拒绝。
- [ ] 未同意时不能生成或读取依赖健康数据的计划与报告；账户、安全、隐私文件、授权管理、导出、删除和注销入口仍可用。
- [ ] 首次同意记录独立的文件类型、版本、时间与来源；重复同意不产生冲突状态。
- [ ] 撤回后立即阻断上述健康读写、计划与报告，不能依赖重新登录、刷新页面或应用重启才生效。
- [ ] 运动记录不能从 Today 快捷入口、应用路由/深链、详情编辑页、控制器或直接 HTTP 调用绕过授权判断。
- [ ] 撤回与正在提交的健康写入并发时，以服务端事务边界给出唯一、可解释结果，不留下半条记录。
- [ ] 重新同意只恢复仍然存在的数据；已删除来源不复活，计划/报告按关键数据变更规则重算或重新生成。

### B. 客户端缓存、提醒与竞态清理

- [ ] 撤回、退出登录和切换账户时，Today、报告、饮食、饮水、运动、睡眠、任务与计划缓存被清除或按用户严格隔离。
- [ ] 撤回健康授权后取消饮水、睡眠和任务提醒；应用生命周期恢复不能把提醒重新注册。
- [ ] 撤回/切号前发出的迟到网络响应不能重新填充旧用户缓存、恢复健康页面或重建提醒。
- [ ] 清理失败有中文可恢复提示，且敏感内容不会继续显示在页面、通知或日志中。

### C. 导出、真实 PDF 与物理清理

- [ ] 导出 PDF 包含真实中文内容：账户、档案、当前及历史计划、各类健康记录、报告目录与正文，而非占位文字或固定样例。
- [ ] PDF 免责声明完整；中文字体嵌入并可提取；字体文件及 PDF 依赖许可证可追溯。
- [ ] PDF 不含内部数据库 ID/字段、密码、验证码、访问/刷新令牌、未脱敏手机号、内部风险原始字段及服务端文件路径。
- [ ] 无密码或错误密码不能打开，加密密码不入库、不入响应、不入日志；正确密码可打开并读取中文。
- [ ] 导出内容使用一致的数据截止点，生成期间新增数据不会造成跨章节时间不一致。
- [ ] 只有所属用户可查看状态和下载；另一用户即使猜到任务 ID 或下载地址也不能访问。
- [ ] 24 小时下载/频率边界在临界前后行为准确；过期后状态与下载均拒绝。
- [ ] 过期、注销、失败重试和服务重启清理数据库状态及服务器物理 PDF/临时文件，不留下半成品。

### D. 按类型/时间删除及来源关联

- [ ] 删除预览由服务端权威计算，确认时重新校验，不信任客户端展示数量。
- [ ] 饮食、饮水、运动、睡眠、每日任务和身体测量支持按类型与时间范围删除，并覆盖起止临界点。
- [ ] 睡眠跨午夜记录按规格定义的醒来日期/业务日期匹配，不因开始时间落在前一天而漏删或误删。
- [ ] 单例健康档案按整类删除，不伪造时间范围语义。
- [ ] 删除来源后，所有引用该来源的日报/周报/月报历史版本及来源组合关系均删除；不相关周期与版本保留。
- [ ] 计划版本通过精确来源测量关联删除，不使用同日猜测；当前计划指针重建到仍存在且可用的版本。
- [ ] “全部健康数据”覆盖授权当前态、计划与报告衍生数据，但保留账户、安全、设备和依法保留的数据。
- [ ] 任一步骤注入失败时同一事务完整回滚：源记录、来源组合、报告、计划版本及当前指针均无半成品。
- [ ] 重复提交相同删除确认给出稳定结果，不扩大删除范围。
