# 轻食记 Healthy 项目建议书

文档编号：LB-PM-001
版本：1.0
日期：2026-09-07
状态：批准立项

## 1. 项目概述

“轻食记 Healthy”是一套面向中国大陆普通成年用户的健康生活管理产品。产品通过健康档案、科学规则和持续记录，为用户生成可解释的饮食、饮水、运动、睡眠及工作生活计划，并用今日执行中心和周期报告帮助用户形成可持续习惯。

产品由品牌 Web、Flutter Android/iOS App、Spring Boot API、管理后台及生产基础设施组成。系统属于生活方式管理工具，不提供疾病诊断、处方或急救服务；高风险用户会被引导寻求专业医疗建议。

## 2. 建设背景与问题

目标用户常同时使用饮食、运动、待办和睡眠等多个工具，数据分散、计划缺乏关联，且许多建议无法说明计算依据。项目拟解决以下问题：

- 健康信息和每日行为记录分散，难以形成完整趋势。
- 通用模板忽略年龄、身体数据、活动水平、偏好和风险差异。
- 用户能记录数据，却缺少明确、低负担的下一步行动。
- AI 建议可能缺乏安全边界，核心指标不可复核。
- 家庭协作、数据导出、隐私授权和账号注销能力不完整。

## 3. 项目目标

1. 建立“登录—建档—生成计划—每日执行—周期复盘—调整计划”的完整闭环。
2. 以规则引擎计算 BMI、BMR、TDEE、营养和活动目标，结果可重复、可解释、可测试。
3. 统一管理饮食、饮水、运动、睡眠和每日任务，支持离线记录与多设备同步。
4. 提供可追溯的日报、周报、月报及个人数据导出。
5. 达到正式上线所需的安全、隐私、支付、监控、备份和回滚要求。
6. Android 与 Web 完成生产发布，iOS 完成同等功能和上架验证。

## 4. 项目范围

### 4.1 范围内

- 手机号验证码、密码、微信和 Apple 登录，设备会话与注销。
- 七步健康档案、风险问卷、授权与测量历史。
- 个性健康计划预览、确认、调整、暂停、恢复和版本历史。
- 今日执行中心与饮食、饮水、运动、睡眠、工作生活任务。
- Health Connect、HealthKit 数据同步及手动记录兜底。
- AI 食物图片识别、人工确认、额度与失败降级。
- 日报、周报、月报、趋势和 PDF/图片导出。
- 免费版、Pro、家庭版、邀请、权益、微信/支付宝及 iOS 内购。
- Web 账户与报告、管理后台、内容与用户支持。
- 国内云部署、备案、监控、告警、备份、恢复和审计。

### 4.2 范围外

- 疾病诊断、远程问诊、处方和医疗器械功能。
- 未经验证的自动治疗建议或药物建议。
- 首发阶段接入所有厂商专有健康平台。
- 未经用户确认便由 AI 识别结果直接写入饮食记录。
- 在无真实流量和团队边界需求时拆分微服务。

## 5. 目标用户与价值

| 用户 | 核心需求 | 项目价值 |
|---|---|---|
| 健康管理用户 | 一处制定并执行生活计划 | 降低记录成本，获得清晰行动建议 |
| 减脂或维持体重用户 | 安全、可解释的目标 | 避免极端目标，持续查看趋势 |
| 家庭成员 | 经授权查看与协作 | 在边界清晰的授权下提供支持 |
| 运营人员 | 管理内容、订单和反馈 | 统一配置、审计和支持流程 |
| 管理员 | 维护系统稳定与安全 | 监控、告警、备份和最小权限控制 |

## 9. 主要风险

| 编号 | 风险 | 等级 | 主要应对 |
|---|---|---:|---|
| R-01 | 健康算法给出不安全目标 | 高 | 规则上下限、风险问卷、专家复核、回归测试 |
| R-02 | 敏感健康数据泄露或越权 | 高 | 用户隔离、加密、最小权限、审计与渗透测试 |
| R-03 | 第三方短信、登录、支付或 AI 不稳定 | 高 | 适配器、超时重试、熔断、降级和对账 |
| R-04 | 隐私、备案或应用市场合规延误 | 高 | 清单前置、法务审查、分阶段送审 |
| R-05 | 多设备与离线同步冲突 | 中 | 幂等操作号、版本控制、冲突提示 |
| R-06 | 健康平台数据重复或边界错误 | 中 | 来源 ID 去重、同步游标、跨午夜测试 |
| R-07 | 性能或容量低于上线要求 | 中 | 容量模型、压测、索引、缓存和告警 |
| R-08 | 范围持续扩张影响交付 | 中 | 基线、变更评审、里程碑门禁 |

## 10. 成功标准

- 需求规格中的 P0/P1 需求全部通过验收，P2 无阻断性缺陷。
- 关键业务自动化测试通过，严重与高危安全问题为零。
- 核心 API 在目标负载下满足性能指标，可用性设计目标不低于 99.9%。
- 数据备份恢复和版本回滚演练通过。
- 用户可完成数据导出、授权撤回和账号注销。
- 发布材料、监控、客服与应急响应准备完整。

## 11. 立项结论

项目目标明确、技术路线成熟、风险可管理，并具备分阶段交付条件。批准立项，采用模块化单体后端与 Flutter 多端方案，按里程碑和质量门禁推进。
