## 1. 测试说明

本文给出 v1.0.0 的核心测试用例、预期结果和最终基线结果。表中的“目标结果：通过”表示规划功能全部完成时必须达到的状态；实际发布必须在“证据”列关联真实 CI、测试平台、扫描或演练记录。没有证据的条目不能仅凭本文视为已实际执行。

## 2. 测试环境

| 环境 | 用途 | 关键要求 |
|---|---|---|
| local | 开发与单元测试 | 模拟短信/第三方，禁止真实用户数据 |
| test | 集成、端到端、沙箱支付 | 独立 MySQL、Redis、对象存储和密钥 |
| device lab | Android/iOS 真机、权限、弱网 | 覆盖当前及前两个主要系统版本 |

| security | 扫描与渗透 | 与生产配置等价，使用隔离测试数据 |
| prod canary | 灰度验证 | 最小用户比例、完整监控和可回滚 |

## 3. 入口与退出标准

入口：需求和设计已基线化；候选制品可部署；迁移、测试账号、合成数据和第三方沙箱可用；阻断缺陷为零。

退出：P0/P1 用例 100% 通过；阻断、严重、高危缺陷为零；性能、安全、恢复、支付对账和隐私权利测试通过；回归结果绑定候选制品摘要。
