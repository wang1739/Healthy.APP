## 1. 验收目的

确认轻食记是否按批准范围完成产品、技术、质量、安全、运维和文档交付，并具备生产发布条件。验收依据为项目建议书、需求规格、项目计划、质量计划及测试报告。

## 2. 验收范围

- Flutter Android/iOS App。
- 品牌与用户 Web、管理后台。
- Spring Boot API、MySQL、Redis、对象存储和第三方适配。
- 账户、健康档案、计划、每日记录、报告、AI、会员家庭与支付。
- 隐私、数据权利、安全、监控、备份、恢复、灰度和回滚。
- 14 项项目文档及运行、客服、应急材料。

## 7. 风险与限制

- R-01：健康规则需随标准和专业复核持续版本化。
- R-02：敏感数据和权限需保持持续扫描、监控和审计。
- R-03：第三方服务具有外部可用性风险，降级路径须定期演练。
- R-04：实际发布须保持备案、隐私文本、SDK 清单和渠道规则有效。
- 产品不提供诊断、治疗、处方或急救服务，免责声明和风险提示必须持续展示。

这些是产品长期运行约束，不构成已批准范围的功能缺失。
