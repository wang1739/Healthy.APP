# 轻食记 Healthy 安全评审报告

文档编号：LB-SEC-011
版本：1.0
日期：2026-09-07
评审基线：v1.0.0 最终交付状态
风险结论：有条件通过

## 1. 执行摘要

系统处理账户、健康、设备、图片和交易信息，安全重点为身份滥用、水平越权、敏感数据泄露、恶意上传、AI 供应商处理、支付伪造和管理权限。最终设计为高风险路径设置了分层控制，目标状态不存在已知严重或高危问题。

本文不声称已代替实际 SAST、DAST、依赖扫描、移动端检查或渗透测试；正式放行必须归档与发布提交一致的工具原始结果和复测证据。

## 2. 数据分类

| 级别 | 示例 | 控制 |
|---|---|---|
| 高敏感 | 健康档案、测量、风险答案、健康平台数据 | 单独同意、加密、最小访问、审计、严格保留期 |
| 敏感 | 手机号、第三方身份、设备、食物照片、位置相关时区 | 脱敏、访问控制、私有存储、目的限制 |
| 交易 | 订单、退款、支付流水标识 | 验签、完整性、对账、财务保留 |
| 内部 | 审计日志、告警、配置元数据 | 角色访问、防篡改、保留策略 |
| 公开 | 品牌内容、公开食谱、协议 | 内容审核和版本管理 |

密码、验证码、Token 和密钥不以可逆明文保存。

## 4. 身份与会话评审

- 验证码单次使用、短期有效并限制错误次数与发送频率。
- 密码使用维护良好的自适应哈希；登录错误不暴露账号存在性。
- Access Token 短期有效，Refresh Token 轮换并检测重用。
- 设备会话可查看和撤销，敏感操作要求重新认证。
- 微信和 Apple 回调验证签名、受众、发行方、时效与随机状态。
- local/test 调试验证码和替身在 prod 启动时被配置校验拒绝。

目标结果：通过。

## 5. 授权与数据隔离

- 普通业务接口只从认证上下文取得用户 ID。
- 家庭共享逐项授权，可撤回，不因家庭关系默认共享全部数据。
- 管理后台与用户端权限域隔离，角色遵循最小权限。
- 对象存储下载使用短期授权并验证所有权。
- 批处理、导出和客服查询使用服务身份与审计。

目标结果：通过，需附跨用户、跨家庭和跨角色自动化/渗透证据。

## 6. API、客户端和上传

- API 设置输入长度、枚举、范围、分页上限、请求体和速率限制。
- CORS 使用明确来源，生产不允许任意通配符携带凭据。
- 错误不返回堆栈、SQL、密钥或内部地址。
- App 使用平台安全存储，禁用发布版敏感调试日志。
- Web 防范 XSS、CSRF、点击劫持并设置安全响应头。
- 图片解码在受限环境处理，移除不必要元数据，生命周期到期删除。

目标结果：通过。

## 7. 支付与会员

- 客户端价格和成功页面不能授予权益。
- 服务端按受信渠道验签、核对商户、订单、金额、币种和状态。
- 回调使用幂等键，状态转换单向受控，重复/乱序可安全处理。
- 退款、撤销、订阅续期和到期通过对账修正。
- 财务与健康数据最小关联，客服展示默认脱敏。

目标结果：通过，需附沙箱/生产验签与对账证据。

## 8. 隐私与合规

- 健康信息单独同意，授权按功能请求且可撤回。
- 首次同意前不初始化非必要 SDK。
- 用户可查询、更正、导出、删除数据和注销账号。
- 第三方 SDK、处理目的、数据类型、保存期和共享对象公开。
- 数据删除与财务/审计法定保留范围分离并向用户说明。
- 跨境处理在发生前单独评估并完成必要程序。

目标结果：通过，正式法律文本需与实际数据流保持一致。

## 9. 基础设施与运维

- test/prod 资源、账号和密钥隔离；密钥由受控服务注入并轮换。
- 数据库与缓存不直接暴露公网，服务身份权限最小化。
- 传输使用 TLS，敏感存储和备份加密。
- 日志脱敏并限制访问，安全审计设置保留与异常告警。
- 漏洞修复、事件分级、隔离、通知、恢复和复盘流程明确。
- 备份恢复和发布回滚定期演练。

目标结果：通过。

## 10. 发布安全门禁

以下任一情况阻止发布：

- 存在未关闭严重或高危漏洞。
- 水平越权、支付伪造、恶意上传或 Token 重用测试失败。
- 生产包含调试验证码、默认密钥或公开对象存储。
- 隐私同意、撤回、数据导出、删除或注销不可用。
- 扫描、渗透、恢复或事件响应证据缺失。

## 11. 结论

最终安全设计覆盖主要威胁并满足 NFR-01、NFR-02、NFR-05、NFR-06、NFR-10 的目标要求，结论为“有条件通过”。放行条件是实际发布提交的 SAST、DAST、依赖与密钥扫描、移动端检查、渗透测试、支付测试和恢复演练全部通过，且原始证据已归档。
