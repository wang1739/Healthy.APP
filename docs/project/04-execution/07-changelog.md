# 轻食记 Healthy 版本更新日志

文档编号：LB-LOG-007
格式：语义化版本 + Keep a Changelog 结构
日期：2026-09-07

## [1.0.0] - 2026-09-07

### 新增

- Android/iOS Flutter App，包含今日、饮食、计划、报告、我的五项导航。
- 手机号验证码、密码、微信、Apple 登录与设备会话管理。
- 七步健康档案、测量历史、风险问卷和健康数据授权。
- 可解释的 BMI、BMR、TDEE、营养、饮水、运动和睡眠计划。
- 今日执行中心、快捷记录、下一步建议与完成度。
- 饮食、饮水、运动、睡眠、工作生活任务和趋势。
- Health Connect 与 HealthKit 同步、来源去重和冲突处理。
- 日报、周报、月报及 PDF/图片导出。
- AI 食物图片识别、候选修改、用户确认与额度控制。
- 免费、Pro、家庭版，家庭授权、微信/支付宝及 iOS 内购。
- 品牌与用户 Web、管理后台、隐私权利和账号注销。
- 生产监控、告警、审计、备份、恢复、灰度和回滚能力。

### 安全

- 用户资源强制按认证主体隔离，管理端采用角色与最小权限。
- Token 轮换与撤销，验证码限流，支付回调验签与幂等。
- 私有对象存储、日志脱敏、密钥托管和依赖/代码扫描。
- 健康风险拦截、AI 人工确认和高危缺陷发布门禁。

### 文档

- 建立项目建议、可行性、需求、计划、Agent、开发日志、质量、评审、测试和验收文档体系。

## [0.3.0] - 生产候选基线

### 新增

- AI 识别、会员家庭、支付、管理后台和 Web 用户端。
- 完整监控、备份、合规材料与应用市场发布流程。

### 变更

- 将第三方集成统一收敛到可替换适配器，并补充超时、熔断和降级。

## [0.2.0] - 核心业务基线

### 新增

- 个性计划、今日聚合、饮食饮水、运动睡眠、每日任务和健康报告。
- 离线队列、幂等操作和多设备冲突处理。

### 变更

- 饮食营养汇总从浏览器本地计算迁移为服务端权威计算。

## [0.1.0] - 平台基线

### 新增

- Flutter 应用壳、Spring Boot API、MySQL、Redis 与 Flyway。
- 账户认证、设备会话、健康档案和风险拦截。
- 自动化测试、基础 CI、统一错误和健康检查。

## 版本规则

- 主版本：存在不兼容的产品、API 或数据变更。
- 次版本：向后兼容的新功能。
- 修订版本：向后兼容的缺陷与安全修复。
- 每次发布记录提交、制品摘要、数据库迁移、配置变化、测试证据和回滚方式。
