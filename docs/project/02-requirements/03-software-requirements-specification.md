# 轻食记 Healthy 软件需求规格说明书

文档编号：LB-SRS-003
版本：1.0
日期：2026-09-07
适用基线：v1.0.0

## 1. 引言

本文定义轻食记正式上线版的功能、数据、接口和非功能需求，是设计、开发、测试及验收的共同基线。系统为生活方式管理工具，不执行疾病诊断、治疗、处方或紧急医疗处置。

## 2. 产品范围与参与者

### 2.1 系统组成

- Flutter Android/iOS App：完整用户业务。
- Web：品牌、下载、账户、报告、导出和隐私设置。
- 管理后台：内容、用户支持、会员订单、反馈、配置和审计。
- Spring Boot API：认证、业务规则、数据、后台任务和第三方集成。
- MySQL、Redis、私有对象存储、监控和备份设施。

### 2.2 用户角色

| 角色 | 权限概述 |
|---|---|
| 游客 | 浏览公开页面、协议和会员说明 |
| 注册用户 | 管理本人档案、计划、记录、报告和授权 |
| 家庭成员 | 仅访问被明确共享的家庭数据 |
| 运营人员 | 管理获授权的内容、反馈和订单信息 |
| 管理员 | 按角色管理系统配置和审计，不默认查看完整敏感数据 |
| 系统任务 | 在最小服务权限下生成报告、通知和对账 |

## 3. 总体业务流程

1. 用户阅读并同意协议，完成注册或登录。
2. 用户建立健康档案并完成风险问卷。
3. 系统按规则生成计划预览，用户确认后生效。
4. 用户在今日中心记录饮食、饮水、运动、睡眠和任务。
5. 系统聚合记录，生成建议、日报、周报和月报。
6. 用户复盘趋势并调整档案或计划，系统保留历史版本。
7. 用户可管理会员、家庭、隐私、数据导出和账号注销。

## 4. 功能需求

### FR-01 账户与认证（P0）

- 支持手机号验证码注册登录、密码登录、微信登录和 Apple 登录。
- Access Token 短期有效，Refresh Token 轮换且可按设备撤销。
- 验证码限制发送频率、有效期、错误次数和重复使用。
- 用户可查看设备、退出单设备或全部设备，并申请注销账号。
- 生产环境不得返回调试验证码或使用开发密钥。

### FR-02 健康档案与风险控制（P0）

- 分步保存基础资料、身体测量、生活方式、饮食偏好、目标和健康授权。
- 记录测量历史、档案版本和完成度，退出后可继续。
- 风险问卷识别未成年人、孕哺期、进食障碍风险、严重慢性病和不安全目标。
- 命中风险时停止普通减脂计划并给出专业求助提示。

### FR-03 个性健康计划（P0）

- 基于档案计算 BMI、BMR、TDEE、热量、营养、饮水、运动和睡眠目标。
- 计算规则具有版本号、上下限和固定输入输出测试。
- 支持预览、确认、调整、重算、暂停、恢复和历史版本查询。
- AI 不得修改核心数值，只能解释既有计算结果。

### FR-04 今日执行中心（P0）

- 按用户本地日期聚合计划、营养、饮水、运动、睡眠、任务、体重和评分。
- 提供快捷记录、下一步建议、未完成事项和空状态。
- 单一模块失败时其他模块仍可展示，并明确标识缺失数据。

### FR-05 饮食管理（P0）

- 支持食物搜索、自定义食物、常用份量、早餐/午餐/晚餐/加餐记录。
- 支持新增、编辑、删除、复制、收藏、餐食模板和每日趋势。
- 服务端统一计算热量及蛋白质、碳水、脂肪，保留精度和计算来源。
- 离线操作联网后按幂等操作号同步，冲突不得静默覆盖。

### FR-06 饮水管理（P1）

- 以毫升保存饮水记录，支持杯量、目标、快捷增加、删除和提醒。
- 修改默认杯量不改写历史记录，跨时区按记录发生时间正确归档。

### FR-07 运动管理（P1）

- 支持手动记录类型、时长、强度和消耗估算。
- Android 支持 Health Connect，iOS 支持 HealthKit，均提供按需授权、撤回和同步状态。
- 系统数据以来源 ID 去重；与手动数据冲突时提示用户处理。

### FR-08 睡眠管理（P1）

- 支持手动记录和系统同步睡眠区间、质量与备注。
- 正确处理跨午夜、时区变化、重复同步和权限撤销。

### FR-09 工作与生活任务（P1）

- 支持任务新增、编辑、完成、跳过、延期、重复规则和提醒。
- 区分计划生成任务和用户任务，均允许用户调整。
- 支持勿扰时段、本地通知和送达状态记录。

### FR-10 健康报告（P1）

- 生成日报、周报、月报，包含趋势、完成率、数据充分性和可解释建议。
- 每个统计值可追溯到原始记录；数据不足时不得生成确定性结论。
- 支持 PDF 或图片导出，重复任务不生成重复报告。

### FR-11 AI 食物识别（P2）

- 支持相机或相册、裁剪压缩、私有上传、异步识别和候选结果。
- 显示置信度；低置信度允许修改或转手动输入。
- 只有用户确认后才创建餐食，失败不重复扣减额度。

### FR-12 会员、家庭与支付（P1）

- 支持免费、Pro、家庭版及服务端权益校验。
- 家庭邀请需双方确认，可退出或撤销，敏感数据按项目授权。
- 支持微信、支付宝和 iOS 内购，回调验签、幂等、退款与对账完整。

### FR-13 Web 用户端（P1）

- 提供品牌介绍、功能、会员、下载、协议和联系信息。
- 登录用户可查看健康概览、报告、数据导出、安全与隐私设置。
- Web 不复制 App 的复杂记录和 AI 拍照流程。

### FR-14 管理后台（P1）

- 支持食物库、食谱、轮播、会员产品、订单、反馈、通知模板和系统配置。
- 管理操作按角色授权，敏感字段默认脱敏，高风险操作写审计日志。
- 普通用户 Token 不能访问任何管理接口。

### FR-15 隐私与个人权利（P0）

- 记录协议版本和同意时间；健康信息取得单独同意并支持撤回。
- 用户可查询、更正、导出、删除个人数据并注销账号。
- 首次同意前不初始化非必要 SDK；展示第三方 SDK 与共享清单。

### FR-16 运维与应急（P0）

- 提供服务、错误率、延迟、连接池、任务积压和第三方失败监控。
- 数据库自动备份，定期执行恢复演练；发布支持灰度与回滚。
- 安全事件具有分级、隔离、通知、取证、恢复和复盘流程。

## 5. 数据需求

- 核心实体使用不可预测唯一 ID，含创建与更新时间。
- 所有用户业务数据必须绑定 `user_id`，服务端从认证主体确定所有权。
- 时间以标准时间存储并按用户时区展示；金额使用最小货币单位或精确类型。
- 密码、Token 和验证码仅保存安全哈希或必要摘要；密钥不得进入 Git。
- 图片和报告存入私有对象存储，通过短期授权访问。
- 关键计划、授权、订单和审计记录保留版本与不可抵赖操作信息。
- 删除遵循业务、财务和法规保留期；到期后执行不可恢复清除。

## 6. 接口需求

- API 前缀统一为 `/api/v1`，JSON 使用 camelCase，时间采用 ISO 8601。
- 错误响应包含 `code`、`message`、`fieldErrors`、`timestamp` 和 `path`。
- 列表接口支持分页、稳定排序和有上限的页大小。
- 写接口校验身份、所有权和输入；关键写入支持幂等键或版本条件。
- 第三方调用设置连接/读取超时、重试上限、熔断和可观测错误分类。
- API 版本变更需保持兼容或提供明确迁移和废弃周期。

## 7. 非功能需求

| 编号 | 类别 | 验收要求 |
|---|---|---|
| NFR-01 | 安全 | 严重和高危已知漏洞为 0；鉴权、越权、注入、上传与支付专项测试通过 |
| NFR-02 | 隐私 | 同意、撤回、导出、删除、注销和 SDK 清单均可验证 |
| NFR-03 | 性能 | 核心读 API P95 ≤ 500 ms，核心写 API P95 ≤ 800 ms，均不含不可控第三方耗时 |
| NFR-04 | 可用性 | 生产月度目标 99.9%，关键第三方失败时有明确降级 |
| NFR-05 | 可靠性 | 核心写操作幂等；报告、通知和支付任务可安全重试 |
| NFR-06 | 恢复 | RPO ≤ 24 小时，RTO ≤ 4 小时；备份恢复与版本回滚演练通过 |
| NFR-07 | 兼容性 | 支持当前及前两个主流 Android/iOS 大版本和现代浏览器最近两个版本 |
| NFR-08 | 易用性 | 主要流程支持大字体、键盘/读屏语义、减少动画及清晰错误提示 |
| NFR-09 | 可维护性 | 模块边界清晰，迁移版本化，关键规则和接口有自动化测试 |
| NFR-10 | 可观测性 | 关键请求含追踪标识，日志脱敏，指标、告警和审计可检索 |

## 8. 业务规则

- 未完成风险评估不得生成普通减脂计划。
- 用户确认前计划预览不改变当前计划；重算产生新版本。
- 未来日期不可新增已发生的健康记录。
- 健康评分必须说明输入数据，不用缺失数据制造高分。
- AI 识别、AI 文案或第三方健康数据不可用时，手动记录和规则解释仍可用。
- 家庭关系不代表默认共享全部健康数据。
- 订单只以服务端验签并确认的支付状态授予权益。
