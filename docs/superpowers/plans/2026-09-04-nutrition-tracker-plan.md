# 饮食记录与每日营养功能页实施计划

1. 创建 `nutrition.html`，完成日期、营养总览、餐食、饮水、建议、趋势、食物弹窗和目标弹窗的语义结构。
2. 创建 `foods.js`，提供不少于 20 种常见食物的每 100 克营养数据与常用份量。
3. 创建 `nutrition.css`，复用轻食记视觉语言并完成桌面、平板和手机响应式布局。
4. 创建 `nutrition.js`，实现按日期存储、餐食增删改、实时营养换算、饮水、目标、建议、趋势和错误提示。
5. 修改首页两个主入口，使其进入 `nutrition.html`。
6. 执行脚本语法、链接、静态资源、页面结构和 Git 差异检查，然后在本地服务器验证 HTTP 响应。
7. 提交代码并推送到 `main` 分支。
