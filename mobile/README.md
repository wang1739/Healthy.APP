# 轻食记 Flutter 应用

该目录是轻食记的 Android / iOS 移动端。当前已完成主题、五项导航、宽屏侧边栏、验证码/密码登录、Token 自动续期与安全存储、登录状态路由守卫，以及首次登录七步健康建档。

建档步骤依次为：基础资料、身体数据、生活方式、作息与运动、饮食偏好、健康目标和风险评估。每一步都会保存到后端，退出后可从服务器记录的步骤继续；完成后才进入 App 主页面。

建档尽量减少输入：日期使用年、月、日三个并排滚轮，睡眠使用滑杆，运动天数、生活方式、饮食与风险信息直接点选；身高、体重、腰围等需要精确快速录入的数值使用数字键盘。

本地 `local` 环境使用调试验证码，点击“获取验证码”后会自动填入。它仅用于开发，生产构建必须接入真实短信并关闭验证码回传。

完整环境要求、启动、测试和打包命令请查看仓库根目录的 `README.md`。
